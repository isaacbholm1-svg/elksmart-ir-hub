# ElkSmart IR Hub

Unofficial IR code database for Ocrustar / ElkSmart USB-C phone IR blasters.

Browse 600+ brands and 3,000+ remotes, then blast any button through an audio-type IR
blaster (19 kHz half-carrier, stereo inverted) or copy it as Pronto hex / raw timings. Codes are loaded live from the open
[IRDB](https://github.com/probonopd/irdb) project.

Not affiliated with Ocrustar or ElkSmart.
