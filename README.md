# ElkSmart IR Hub

Unofficial IR code database for Ocrustar / ElkSmart USB-C phone IR blasters.

Browse 900+ brands and 5,000+ remotes, then copy any button as Pronto hex or raw timings
to use in your IR blaster app. Codes are loaded live from the open
[IRDB](https://github.com/probonopd/irdb) project.

Not affiliated with Ocrustar or ElkSmart.
